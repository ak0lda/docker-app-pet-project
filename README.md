# 🐳 Docker Basics: Static Website with Nginx

Простой демонстрационный проект для подтверждения базовых навыков работы с **Docker** и **Docker Compose**. Проект показывает, как контейнеризировать статическое веб-приложение, настраивать веб-сервер и управлять конфигурацией.

## 🛠️ Что я умею (Ключевые навыки в проекте)
* **Контейнеризация**: Написание кастомного `Dockerfile` для сборки независимого production-ready образа.
* **Оркестрация**: Использование `docker-compose.yml` для быстрого развертывания окружения одной командой.
* **Управление данными (Volumes)**: Настройка `bind mounts` для мгновенного обновления кода в процессе разработки (hot-reload) без пересборки образа.
* **Сети и порты**: Проброс портов (`port forwarding`) для доступа к приложению из локальной сети.

## 📦 Стек технологий
* **Docker** & **Docker Compose**
* **Nginx** (Web Server)
* **HTML5 / CSS3**

## 🚀 Как запустить проект

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd YOUR-REPO-NAME
   ```

2. Запустите контейнер в режиме разработки (с поддержкой Volumes):
   ```bash
   docker-compose up -d
   ```
   *После этого сайт будет доступен по адресу `http://localhost:8080`. Любые изменения в папке `/site` сразу отобразятся на странице.*

3. Сборка чистого Production-образа (файлы «вшиваются» внутрь):
   ```bash
   docker build -t static-nginx-blog .
   ```
